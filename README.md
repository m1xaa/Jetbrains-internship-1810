# Jetbrains Internship Task 1810

This repository contains the solution to JetBrains Internship Task 1810. It contains five markdown files in docs/architecture. 

- `01-overview.md` - described an overall architecture of a system with initial assumptions
- `02-snowflake-ingestion.md` - documents the ways in which data can be loaded into our meta DWH
- `03-data-model.md` - described the data model of our DWH including granularity, relationships and proposed tables
- `04-transformations.md` - describing the process of loading data from raw tables into the fact and dimension tables
- `05-analytics.md` - sql queries on our meta DWH that answer task's questions.
